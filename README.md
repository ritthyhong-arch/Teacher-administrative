# ប្រព័ន្ធត្រួតពិនិត្យរដ្ឋបាលគ្រូប្រចាំថ្ងៃ (Daily Teacher Administration Monitoring System)
### សាលាបញ្ញាសាស្រ្តអន្តរជាតិ (Paññāsāstra International School - PSIS)

ប្រព័ន្ធគ្រប់គ្រង និងត្រួតពិនិត្យរដ្ឋបាលគ្រូបង្រៀនប្រចាំថ្ងៃ បង្កើតឡើងដោយផ្អែកលើទម្រង់របាយការណ៍ក្រដាសជាក់ស្តែងរបស់សាលាបញ្ញាសាស្រ្តអន្តរជាតិ ជាមួយនឹងចំណុចប្រទាក់ជាភាសាខ្មែរ ១០០% ស្រស់ស្អាត ទំនើប ងាយស្រួលប្រើប្រាស់ និងមានមុខងារស្វ័យប្រវត្តភាវូបនីយកម្មខ្ពស់។

---

## 🌟 លក្ខណៈពិសេសចម្បងៗ (Core Features & Capabilities)

### ១. ការគ្រប់គ្រងទិន្នន័យមូលដ្ឋាន (Master Data Management)
- **ព័ត៌មានគ្រូបង្រៀន (Teacher Profiles):**
  - ផ្ទុកទិន្នន័យគ្រូជាក់ស្តែងរបស់សាលា៖ `ហេង ឆេងលី`, `ព្រះអង្គគ្រូ ស៊ន ប៉ោធី`, `បេន វី`, `ក ធារិទ្ធ`, `ហុក វិសាល`, `ហែម អឿន`, និងគ្រូដទៃទៀត។
  - ចែកតាមកម្រិតសិក្សា៖ មត្តេយ្យ (Kindergarten - K2), បឋមសិក្សា (Primary - ថ្នាក់ទី១ ដល់ ទី៦), និង មធ្យមសិក្សា (Secondary - ថ្នាក់ទី៧ ដល់ ទី១២)។
  - វេនបង្រៀន៖ វេនព្រឹក (Morning) និង វេនល្ងាច (Afternoon)។
  - មុខងារ បន្ថែម កែប្រែ និងលុបព័ត៌មានគ្រូ។
- **កាលវិភាគបង្រៀនប្រចាំសប្តាហ៍ (Weekly Schedule Mapping):**
  - ចាត់ចែងគ្រូ និងថ្នាក់ជាក់លាក់តាមថ្ងៃក្នុងសប្តាហ៍ពី **ថ្ងៃចន្ទ ដល់ សុក្រ**។
  - តារាងត្រួតពិនិត្យប្រចាំថ្ងៃនឹងទាញយកទិន្នន័យគ្រូដែលត្រូវបង្រៀននៅថ្ងៃនោះ និងវេននោះដោយស្វ័យប្រវត្ត!

### ២. ផ្ទាំងត្រួតពិនិត្យប្រចាំថ្ងៃ (Daily Monitoring Dashboard)
- **ប្រព័ន្ធចម្រាញ់ទិន្នន័យ (Smart Filters):**
  - ជ្រើសរើសថ្ងៃខែឆ្នាំ (Date Picker) ជាមួយប៊ូតុងរហ័ស (ថ្ងៃនេះ, ម្សិលមិញ, ថ្ងៃស្អែក, ថ្ងៃគំរូ ០៥ តុលា ២០២៦)។
  - ចម្រាញ់តាមវេន (ព្រឹក/ល្ងាច)។
  - ចម្រាញ់តាមកម្រិតសិក្សា (មត្តេយ្យ, បឋមសិក្សា, មធ្យមសិក្សា)។
  - ចម្រាញ់តាមស្ថានភាព (បំពេញរួចរាល់, ខ្វះកិច្ចការរដ្ឋបាល, សុំច្បាប់, មកយឺត)។
  - ប្រអប់ស្វែងរកឈ្មោះគ្រូ ឬថ្នាក់រហ័ស។
- **តារាងត្រួតពិនិត្យអន្តរកម្ម (Interactive Checklist Table) តាមគំរូសាលាជាក់ស្តែង៖**
  1. `ល.រ` (No.)
  2. `ឈ្មោះគ្រូ` (Teacher Name)
  3. `ថ្នាក់` (Class/Grade)
  4. `ម៉ោងស្កេនចូល` (Scan-In Time - Time picker និងប៊ូតុង "ឥឡូវ")
  5. `ស្រង់វត្តមានសិស្ស` (Student Attendance - Toggle: បានស្រង់ / មិនបានស្រង់)
  6. `វាយតម្លៃពិន្ទុសិស្ស` (Score Evaluation - Toggle: បានដាក់ពិន្ទុ / មិនបានដាក់)
  7. `ការប្រើប្រាស់ Telegram` (Telegram Usage - Toggle: បានប្រើ / មិនបានប្រើ)
  8. `សម្រង់អត្ថបទ` (Lesson Summary - Toggle: បានសរសេរ / មិនបានសរសេរ)
  9. `ម៉ោងស្កេនចេញ` (Scan-Out Time - Time picker និងប៊ូតុង "ឥឡូវ")
  10. `ផ្សេងៗ / ស្ថានភាព` (Remarks - ធម្មតា, ច្បាប់, យឺត, គ្មានច្បាប់ + កំណត់សម្គាល់)
  11. `សកម្មភាព` (Row Action - ប៊ូតុង "បំពេញគ្រប់" តែម្តង)
- **លក្ខខណ្ឌពិសេស (Strict Requirement Rule):**
  - នៅពេលជ្រើសរើស **"ច្បាប់" (On Leave)** ប្រព័ន្ធនឹង **បិទ និងធ្វើឲ្យប្រផេះ (gray out & disable) ជួរឈរទី ៤ ដល់ទី ៩** ដោយស្វ័យប្រវត្ត!
- **សកម្មភាពរួម (Bulk Actions):**
  - "បំពេញរួចរាល់ទាំងអស់" (Mark All Completed) សម្រាប់គ្រូទាំងអស់ក្នុងថ្ងៃនោះ។
  - ប៊ូតុងសកម្មភាពរហ័សតាមជួរឈរ (ស្រង់វត្តមានទាំងអស់, ដាក់ពិន្ទុទាំងអស់, ប្រើ Telegram ទាំងអស់, សរសេរសម្រង់ទាំងអស់, ម៉ោងចូល/ចេញស្វ័យប្រវត្ត)។

### ៣. របាយការណ៍សង្ខេប និងការជូនដំណឹង (Summary Analytics & Alerts)
- **ផ្ទាំងស្ថិតិ KPI សង្ខេបខាងលើ៖**
  - គ្រូត្រូវបង្រៀនសរុប (Total Scheduled Teachers)
  - វត្តមាន (Present)
  - សុំច្បាប់ (On Leave)
  - ស្កេនចូលយឺត (Late Scan-In)
  - ខ្វះកិច្ចការរដ្ឋបាល (Incomplete Admin Tasks)
  - អត្រាអនុវត្តពេញលេញ (% Completion Rate)
- **ការសម្គាល់ពណ៌ (Alert Highlights):**
  - ពណ៌លឿងស្រាល៖ គ្រូខ្វះកិច្ចការរដ្ឋបាល ឬខកខានស្កេនចេញ/ចូល។
  - ពណ៌ទឹកក្រូចស្រាល៖ គ្រូមកស្កេនចូលយឺតជាងម៉ោងកំណត់។
  - ពណ៌ប្រផេះស្រាល៖ គ្រូសុំច្បាប់។

### ៤. របាយការណ៍បោះពុម្ពផ្លូវការ & នាំចេញ (Official Print & Export)
- **ទម្រង់បោះពុម្ពលើក្រដាស A4 ផ្លូវការរបស់សាលាបញ្ញាសាស្រ្តអន្តរជាតិ (PSIS):**
  - **ក្បាលលិខិតផ្នែកខាងលើ៖**
    - កណ្តាល/ស្តាំ៖ `ព្រះរាជាណាចក្រកម្ពុជា / ជាតិ សាសនា ព្រះមហាក្សត្រ` (អក្សរមូលផ្លូវការ)
    - ឆ្វេង៖ `សាលាបញ្ញាសាស្រ្តអន្តរជាតិ / វិន័យ គុណធម៌ សុភមង្គល` ព្រមទាំងរូបសញ្ញាសាលា (PSIS Seal)
    - ចំណងជើង៖ `របាយការណ៍ត្រួតពិនិត្យរដ្ឋបាលគ្រូប្រចាំថ្ងៃ`
  - **តារាងទិន្នន័យផ្លូវការ៖** បន្ទាត់ និងព្រំដែនច្បាស់ស្អាត មិនកាត់ទំព័រផ្តេសផ្តាស និងរៀបចំក្បាលតារាងដដែលៗនៅពេលបោះពុម្ពច្រើនទំព័រ។
  - **ប្លុកហត្ថលេខាផ្លូវការផ្នែកខាងក្រោម៖**
    - ឆ្វេង៖ `បានឃើញ និង ឯកភាព` / `នាយិកាសាខា`
    - ស្តាំ៖ **កាលបរិច្ឆេទចន្ទគតិខ្មែរស្វ័យប្រវត្ត** (ឧ. `ថ្ងៃ ចន្ទ ៩រោច ខែភទ្របទ ឆ្នាំមមី អដ្ឋស័ក ពុទ្ធសករាជ ២៥៧០ / ត្រូវនឹងថ្ងៃទី៥ ខែតុលា ឆ្នាំ២០២៦`) អមដោយ `អ្នកត្រួតពិនិត្យ`។
- **ការនាំចេញជា Excel (.xlsx):**
  - នាំចេញរបាយការណ៍ប្រចាំថ្ងៃជាឯកសារ Excel (.xlsx / .xml) មានក្បាលលិខិត ពណ៌ និងទម្រង់រៀបរយ។
  - នាំចេញរបាយការណ៍សង្ខេបប្រចាំខែជា Excel។

### ៥. មុខងារបន្ថែមសម្រាប់រដ្ឋបាលសាលា (Added Admin Tools)
- **នាំចូលទិន្នន័យស្កេនមេដៃ (Biometric Import):** អាចនាំចូលទិន្នន័យ CSV ចេញពីម៉ាស៊ីន Fingerprint/Face Attendance ហើយផ្គូផ្គងឈ្មោះគ្រូស្វ័យប្រវត្ត!
- **ការរក្សាទុកទិន្នន័យ (Data Persistence):** ប្រើប្រាស់ LocalStorage រួមទាំងមានមុខងារទាញយក Backup JSON និង Restore មកវិញបានយ៉ាងងាយស្រួល។

## 🚀 របៀបបើកដំណើរការ (How to Run)

### ជម្រើសទី ១ (ងាយស្រួលបំផុតលើ Windows):
ចុចពីរដង (Double click) លើឯកសារ `start.bat` ប្រព័ន្ធនឹងបើក Web Browser ដោយស្វ័យប្រវត្ត។

### ជម្រើសទី ២ (ប្រើប្រាស់ Python Server):
```bash
python run_server.py
```
បន្ទាប់មកបើក Browser ទៅកាន់៖ `http://localhost:8080/index.html`

### ជម្រើសទី ៣ (បើកផ្ទាល់ដោយមិនបាច់មាន Server):
ចុចពីរដងលើឯកសារ `index.html` ដើម្បីបើកក្នុង Google Chrome, Microsoft Edge, Firefox, ឬ Safari ភ្លាមៗ។
